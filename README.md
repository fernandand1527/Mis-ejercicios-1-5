## 🚀 Descripción del Proyecto
Este repositorio contiene la evolución de mis ejercicios técnicos, integrando el diseño de bases de datos relacionales y la maquetación web avanzada.

### 📂 Contenido Principal
* **Base de Datos `BANCO`**: Esquema SQL para la gestión de usuarios y cuentas bancarias.
* **Maquetación Web**: Uso intensivo de `divs`, selectores específicos e inline CSS.
* **Accesibilidad**: Implementación de clases `.hidden` para lectores de pantalla.
